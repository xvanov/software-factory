1"""Gate: ``acceptance-verified`` (WS1.2 — independent acceptance oracle). 

2 

3The problem this closes 

4======================= 

5 

6Loop-4 makes the dev author AND run its own tests. That is great for 

7convergence, but a coder that writes the tests judging it can reward-hack — 

8special-case the exact assertions, weaken them, or delete the hard ones 

9(ImpossibleBench: hiding the acceptance tests from the coder drops cheating to 

10~0). Every other merge gate re-derives truth from artifacts the dev produced 

11(``tests-green`` re-runs the dev's suite; ``tests-meaningful`` scans the dev's 

12tests). None of them is INDEPENDENT of the dev. 

13 

14This gate is that independent layer. It runs an acceptance test authored from 

15the direction's acceptance criteria — the SPEC ONLY, blind to the dev's code 

16and the dev's tests — that the dev never sees or edits (authored at story spawn, 

17stored under ``state/acceptance/<app>/<story_id>/`` OUTSIDE the dev worktree; 

18see ``factory.chain.acceptance``). At merge time this gate copies that test into 

19the merge-candidate checkout, runs it against the app's python env, and passes 

20iff it exits 0 AND at least one test actually passed — so a story whose OWN 

21tests are green but whose behaviour violates an acceptance criterion is caught 

22here. 

23 

24What "blocking" keys off 

25======================== 

26 

27Required-ness is a property of the APP, not of a database flag: once 

28``gates.acceptance_oracle`` is on, ``required_gate_labels`` requires this label 

29for every non-docs story, and THIS gate decides applicability. Per-story 

30expectation is re-derived from the spec by 

31``acceptance.acceptance_expected_for_story`` (flag → ref → the direction on 

32disk), because the flag is written by a best-effort DB write: a lost write used 

33to leave ``acceptance_expected=0`` on a story that must be gated, and both the 

34gate and the required set then read that as "no acceptance criteria, skip" and 

35shipped it un-gated. 

36 

37Resolution 

38========== 

39 

40* Not opted in (``gates.acceptance_oracle`` False): PASS (skip). Never required. 

41* Opted in, story genuinely has no acceptance criteria: PASS (not applicable). 

42* Opted in, expectation cannot be established (no story row, unresolvable 

43 direction): AUTHORITATIVE BLOCK — never a silent pass. 

44* Expected + stored test readable: 

45 - real-run (checkout present): copy in, run, pass iff exit 0 AND the run 

46 reports at least one passing test, remove. 

47 - dry-run / no checkout: NON-AUTHORITATIVE (cannot verify), never a pass. 

48* Expected + stored test MISSING/unreadable (authoring flaked): AUTHORITATIVE 

49 BLOCK (passed=False, authoritative=True) — self-heal re-authors next tick, 

50 up to ``acceptance._MAX_AUTHOR_PASSES`` passes, after which it stays blocked 

51 and names the exhaustion for the operator. 

52* Any infrastructure error inside this gate (copy failed, command template 

53 broken, unexpected exception): AUTHORITATIVE BLOCK. A raised exception here 

54 used to escape ``evaluate_all_gates`` and abort the entire merge evaluation. 

55"""

77# THIS interpreter, not a bare ``python`` resolved through PATH. 

78# 

79# The oracle authors Hypothesis PROPERTY tests from EARS-form acceptance criteria 

80# (WS4.3), so a generated test opens with ``from hypothesis import given`` — and 

81# ``hypothesis`` is a DEV EXTRA of this project. Bare ``python`` resolves through 

82# PATH to whatever the caller inherited; inside the dev sandbox that is a sibling 

83# app's venv (an interactive shell's rc file prepends it), which has no 

84# hypothesis. Collection then died with ModuleNotFoundError and the gate returned 

85# exit_code=2. 

86# 

87# That is a FALSE BLOCK, and an expensive one: the gate is required, so the story 

88# was re-dispatched to dev with an IDENTICAL failure signature until it exhausted 

89# its retries and sank to blocked_tests_need_clarification. Observed on stories 

90# 148 and 157 (2026-07-30); in both cases the dev's code was fine and the harness 

91# was broken. 

92# 

93# ``sys.executable`` is the fix rather than ``uv run``: the oracle runs the test in 

94# a bare temp directory with no ``pyproject.toml``, so ``uv run`` would find no 

95# project, build an ephemeral env, and still lack hypothesis. The interpreter 

96# already running the factory is by construction the one whose env satisfies the 

97# factory's own dev extras. 

98# 

99# It is only a DEFAULT, and for a real app it is usually the wrong one: an app 

100# whose deps are not in the factory's env MUST set ``acceptance_test_command`` 

101# (plus ``acceptance_test_dir`` / ``acceptance_test_cwd``) so the oracle runs in 

102# the app's own harness — and must then guarantee hypothesis in that env if any 

103# of its acceptance criteria are EARS-shaped. 

104# ``-B`` (no bytecode) plus ``-p no:cacheprovider`` keep the run from leaving a 

105# compiled ``__pycache__`` copy of the hidden oracle, or a ``.pytest_cache`` entry 

106# naming its tests, inside the checkout. The sweep removes both anyway; not 

107# creating them is cheaper and still right if the sweep never gets to run. 

108_DEFAULT_ACCEPTANCE_COMMAND = ( 

109 f"{sys.executable} -B -m pytest {{test_file}} -q -p no:cacheprovider" 

110) 

111 

112# "N passed" in pytest's summary line. Used to refuse a VACUOUS pass: a file whose 

113# every test is skipped (the persona is told to ``pytest.skip`` criteria that are 

114# untestable as written) exits 0 while verifying nothing, and exit-0-means-pass 

115# would have turned that into a merge-authoritative green. 

116_PASSED_RE = re.compile(r"(\d+) passed") 

117# Enough of a pytest summary to know the run was READABLE even when nothing 

118# passed ("1 skipped in 0.01s" carries no "passed" token at all). 

119_SUMMARY_RE = re.compile( 

120 r"(\d+) (passed|failed|skipped|error|errors|xfailed|xpassed|deselected)|no tests ran" 

121)

124def _fmt_command(template: str, *, test_file: str) -> str: 

125 """Substitute ``{test_file}`` by literal replacement. 

126 

127 NOT ``str.format``: a template containing any other brace (a shell brace 

128 expansion, a jq filter) raised ``KeyError`` from inside the gate, and that 

129 exception escaped into ``evaluate_all_gates`` and killed the whole merge 

130 evaluation for the app rather than failing this one gate. 

131 """ 

132 return template.replace("{test_file}", test_file)

135def _resolve_subdir(repo_root: Path, rel: str | None, *, what: str) -> Path: 

136 """Resolve a repo-relative config path, refusing to escape the checkout.""" 

137 base = Path(repo_root).resolve() 

138 if not rel or not rel.strip(): 

139 return base 

140 target = (base / rel.strip()).resolve() 

141 if base != target and base not in target.parents: 

142 raise ValueError(f"{what}={rel!r} resolves outside the checkout ({target})") 

143 if not target.is_dir(): 

144 raise ValueError(f"{what}={rel!r} does not exist in the checkout ({target})") 

145 return target

148def _git_common_dir(repo_root: Path) -> Path | None: 

149 """The checkout's shared git dir (``.git``, or the worktree's parent gitdir).""" 

150 try: 

151 proc = subprocess.run( # noqa: S603,S607 - fixed argv, no shell 

152 ["git", "rev-parse", "--git-common-dir"], 

153 cwd=str(repo_root), 

154 capture_output=True, 

155 text=True, 

156 timeout=15, 

157 ) 

158 except (OSError, subprocess.SubprocessError): 

159 return None 

160 if proc.returncode != 0: 

161 return None 

162 out = proc.stdout.strip() 

163 if not out: 

164 return None 

165 p = Path(out) 

166 return p if p.is_absolute() else (Path(repo_root) / p)

169def _exclude_oracle_from_git(repo_root: Path) -> None: 

170 """Make a leaked oracle copy un-committable in this checkout. 

171 

172 Defense in depth for the independence guarantee. The checkout the gate runs in 

173 IS the story's dev worktree, and the chain does a deterministic ``git add -A`` 

174 + commit on the dev's green pass (``handlers._commit_green_dev_work``). If a 

175 crash ever leaves a copy behind, that commit would publish the hidden oracle 

176 into the PR. A local ``.git/info/exclude`` entry keeps ``add -A`` from staging 

177 it even then. Best-effort and local-only — never written to the repo tree. 

178 """ 

179 common = _git_common_dir(repo_root) 

180 if common is None: 

181 return 

182 try: 

183 info = common / "info" 

184 info.mkdir(parents=True, exist_ok=True) 

185 excl = info / "exclude" 

186 pattern = ORACLE_COPY_GLOB 

187 existing = excl.read_text(encoding="utf-8") if excl.exists() else "" 

188 if pattern in existing: 

189 return 

190 sep = "" if existing.endswith("\n") or not existing else "\n" 

191 excl.write_text( 

192 f"{existing}{sep}# factory acceptance oracle (never committed)\n{pattern}\n", 

193 encoding="utf-8", 

194 ) 

195 except OSError: 

196 return

199def evaluate(pr: PRContext, app_config: AppConfig) -> GateResult: 

200 """Run the gate, converting ANY unexpected error into an authoritative block.""" 

201 try: 

202 return _evaluate(pr, app_config) 

203 except Exception as exc: # noqa: BLE001 - a broken detector must block, not raise 

204 return GateResult( 

205 label="acceptance-verified", 

206 passed=False, 

207 reason=( 

208 "acceptance oracle gate FAILED to run " 

209 f"({type(exc).__name__}: {exc}) — blocking (fail-closed)" 

210 ), 

211 details={"authoritative": True, "infra_error": repr(exc)[:500]}, 

212 )

215def _evaluate(pr: PRContext, app_config: AppConfig) -> GateResult: 

216 label = "acceptance-verified" 

217 gates = app_config.gates 

218 

219 # Not opted in: skip (pass). Mirrors the optional command gates — a missing 

220 # capability means "this gate does not apply", not "this gate fails". 

221 if not gates.acceptance_oracle: 

222 return GateResult( 

223 label=label, 

224 passed=True, 

225 reason="acceptance oracle not enabled for this app (skipped)", 

226 details={"acceptance_oracle": False}, 

227 ) 

228 

229 story = pr.story 

230 ref = getattr(story, "acceptance_test_ref", None) if story is not None else None 

231 root = pr.software_factory_root 

232 

233 # Re-derived from the SPEC, never trusted from the DB flag alone. 

234 expected, source = acceptance_expected_for_story(story, app_config, root) 

235 if not expected: 

236 # Opted in, but this story has no acceptance criteria to verify — not 

237 # applicable. (Only ever reached when the direction was resolvable and 

238 # genuinely carries no criteria.) 

239 return GateResult( 

240 label=label, 

241 passed=True, 

242 reason="story has no acceptance criteria (not applicable, skipped)", 

243 details={ 

244 "acceptance_oracle": True, 

245 "acceptance_expected": False, 

246 "expected_source": source, 

247 }, 

248 ) 

249 

250 # Expected but the stored oracle is missing/unreadable → authoring flaked, or 

251 # there is no story row to author for at all. BLOCK AUTHORITATIVELY (never a 

252 # silent pass). The tick self-heal (reauthor_missing_oracles) re-authors it 

253 # before a later merge attempt, so this is not normally a dead-end; once the 

254 # authoring pass ceiling is exhausted it IS a dead-end that names itself. 

255 if not ref_is_readable(story, root): 

256 exhausted = author_exhausted(story, root) 

257 passes = ( 

258 author_passes(Path(root), story.app, story.id) 

259 if story is not None and root is not None 

260 else 0 

261 ) 

262 tail = ( 

263 " — authoring EXHAUSTED its pass ceiling; the operator must fix the " 

264 "direction's acceptance criteria or the app's acceptance harness config" 

265 if exhausted 

266 else " — authoring failed; blocking until it is re-authored (self-heals next tick)" 

267 ) 

268 return GateResult( 

269 label=label, 

270 passed=False, 

271 reason=( 

272 "acceptance oracle EXPECTED but not available " 

273 f"(ref={ref!r}, root={'set' if root else 'unset'}, " 

274 f"expected_source={source}){tail}" 

275 ), 

276 details={ 

277 "authoritative": True, 

278 "acceptance_expected": True, 

279 "acceptance_test_ref": ref, 

280 "expected_source": source, 

281 "author_passes": passes, 

282 "author_exhausted": exhausted, 

283 }, 

284 ) 

285 

286 # Need a real checkout to run against. Dry-run (no worktree) cannot 

287 # re-derive truth — never claim a merge-authoritative pass. 

288 if pr.dry_run or pr.repo_root is None: 

289 return GateResult( 

290 label=label, 

291 passed=False, 

292 reason="[dry-run] acceptance oracle present but not run (no checkout)", 

293 details={"authoritative": False, "acceptance_test_ref": ref}, 

294 ) 

295 

296 # Real-run: copy the independent test into the merge-candidate checkout, 

297 # run it against the app's env, then remove it (never leave it behind to be 

298 # committed). Named distinctively (story id, else head_sha) so it cannot 

299 # collide with app tests. 

300 # ref_is_readable(story, root) returned True above → story, ref, root all set. 

301 assert story is not None and ref is not None and root is not None 

302 repo_root = Path(pr.repo_root) 

303 sid = story.id if story.id is not None else pr.head_sha 

304 dest_name = f"{ORACLE_COPY_PREFIX}{sid}.py" 

305 

306 # WHERE the file goes and WHERE the command runs. Defaults are the checkout 

307 # root; a real app almost always needs both (sacrifice: ``backend/tests`` and 

308 # ``backend``), because a python file dropped at the repo root can neither 

309 # import the app package nor pick up the conftest that provides its test env. 

310 dest_dir = _resolve_subdir(repo_root, gates.acceptance_test_dir, what="acceptance_test_dir") 

311 run_cwd = _resolve_subdir(repo_root, gates.acceptance_test_cwd, what="acceptance_test_cwd") 

312 dest = dest_dir / dest_name 

313 

314 # Any copy left behind by an earlier interrupted run is removed BEFORE this 

315 # one, and the pattern is excluded from git, so a leaked oracle can neither be 

316 # read by the dev on a later cycle nor committed into the PR. 

317 swept_before = sweep_leaked_oracles(repo_root) 

318 _exclude_oracle_from_git(repo_root) 

319 

320 p = Path(ref) 

321 stored = p if p.is_absolute() else Path(root) / p 

322 

323 try: 

324 rel_for_cmd = dest.relative_to(run_cwd).as_posix() 

325 except ValueError: 

326 # dest is not under the cwd (e.g. dir=backend/tests, cwd=backend/app): 

327 # an absolute path is always valid for pytest. 

328 rel_for_cmd = dest.as_posix() 

329 

330 cmd_template = gates.acceptance_test_command or _DEFAULT_ACCEPTANCE_COMMAND 

331 if "{test_file}" not in cmd_template: 

332 # A command that never names the oracle does not run it. Exit 0 would then 

333 # be a green gate that verified nothing at all — the worst kind of 

334 # fail-open, produced by a single config typo. 

335 raise ValueError( 

336 "gates.acceptance_test_command must contain '{test_file}' " 

337 f"(got {cmd_template!r}) — a command that does not name the oracle " 

338 "cannot be evidence that it ran" 

339 ) 

340 cmd = _fmt_command(cmd_template, test_file=rel_for_cmd) 

341 swept_after: list[str] = [] 

342 try: 

343 shutil.copyfile(stored, dest) 

344 exit_code, output = _run_command(cmd, cwd=run_cwd) 

345 finally: 

346 # The sweep IS the cleanup: it removes this run's copy and anything an 

347 # earlier crash left elsewhere in the tree. 

348 swept_after = sweep_leaked_oracles(repo_root) 

349 

350 details: dict[str, object] = { 

351 "authoritative": True, 

352 "acceptance_test_ref": ref, 

353 "expected_source": source, 

354 "command": cmd, 

355 "cwd": str(run_cwd), 

356 "test_file": rel_for_cmd, 

357 "exit_code": exit_code, 

358 "swept_before_run": swept_before, 

359 "swept_after_run": swept_after, 

360 "output_tail": output, 

361 } 

362 

363 # The copy MUST be gone. If it is not, the oracle is sitting in the dev's 

364 # worktree — block rather than pass, because passing here would leave the next 

365 # dev cycle able to read the hidden test (and the chain's ``git add -A`` able 

366 # to commit it). 

367 if dest.exists(): 

368 details["leaked_copy"] = str(dest) 

369 return GateResult( 

370 label=label, 

371 passed=False, 

372 reason=( 

373 f"acceptance oracle copy could not be removed from the checkout ({dest}) — " 

374 "blocking to protect dev-blindness" 

375 ), 

376 details=details, 

377 ) 

378 

379 if exit_code != 0: 

380 return GateResult( 

381 label=label, 

382 passed=False, 

383 reason=f"ran independent acceptance oracle exit_code={exit_code}", 

384 details=details, 

385 ) 

386 

387 # Exit 0 is not enough. A pytest run in which every test SKIPPED also exits 0 

388 # while verifying nothing, and the persona is explicitly allowed to emit 

389 # ``pytest.skip`` for a criterion that is untestable as written — so 

390 # "exit 0 → merge-authoritative green" would ship an un-verified story with a 

391 # gate that claims to have checked it. Require positive evidence instead. 

392 # 

393 # The count is read from the OUTPUT, not gated on the command string: an app 

394 # whose command is a wrapper (``make acceptance``) still prints pytest's 

395 # summary, and keying off ``"pytest" in cmd`` would have skipped the check for 

396 # exactly those apps. Only a run whose output carries no summary at all is 

397 # unjudgeable — and then the command decides: if it named pytest we expected a 

398 # summary and its absence is itself suspicious (block); otherwise the app owns 

399 # a runner we cannot read and exit 0 is all we have. 

400 m = _PASSED_RE.search(output) 

401 if m is not None or _SUMMARY_RE.search(output) is not None: 

402 n_passed = int(m.group(1)) if m is not None else 0 

403 details["tests_passed"] = n_passed 

404 if n_passed < 1: 

405 return GateResult( 

406 label=label, 

407 passed=False, 

408 reason=( 

409 "acceptance oracle exited 0 but reported NO passing test " 

410 "(vacuous run — every criterion skipped, or nothing collected); " 

411 "blocking rather than crediting a verification that did not happen" 

412 ), 

413 details=details, 

414 ) 

415 elif "pytest" in cmd: 

416 details["tests_passed"] = None 

417 return GateResult( 

418 label=label, 

419 passed=False, 

420 reason=( 

421 "acceptance oracle exited 0 but produced no pytest result summary " 

422 "(nothing ran, or the output was suppressed) — blocking rather than " 

423 "crediting a verification that cannot be evidenced" 

424 ), 

425 details=details, 

426 ) 

427 else: 

428 # A non-pytest runner we cannot read: exit 0 is all we have. Recorded so an 

429 # operator can see the gate's evidence was weaker here. 

430 details["tests_passed"] = None 

431 details["vacuity_check"] = "skipped (unreadable non-pytest runner output)" 

432 

433 return GateResult( 

434 label=label, 

435 passed=True, 

436 reason=f"ran independent acceptance oracle exit_code={exit_code}", 

437 details=details, 

438 )
