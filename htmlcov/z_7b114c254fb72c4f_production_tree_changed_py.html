1"""Gate: ``production-tree-changed``. 

2 

3The story's diff must change at least one PRODUCTION file. FAIL-CLOSED: a diff 

4this gate cannot see is a diff it refuses to bless. 

5 

6Why this gate exists (measured, 2026-08-04) 

7------------------------------------------- 

8The chain was graded against a hidden oracle for the first time: 7/19 resolved, 

9and its own green verdict was 40% precise (6 of 15 "green" rows actually 

10passed). Every check the chain runs measures agreement with artifacts the chain 

11itself produced — the dev writes the code AND the tests, the reviewer's approve 

12rule reads a ``test_quality_score``, the merge gate re-runs the dev's own 

13tests. One row, ``harumiweb__exstruct-113``, spent $2.45, edited ONLY 

14``tests/cli/test_cli_lazy_imports.py``, was approved by the reviewer at 

15``test_quality_score=0.90``, reached ``reviewer_done``, and recorded 

16``files_changed: []`` / ``diff_bytes: 0``. Nothing in the chain noticed that 

17the production tree was untouched, because nothing was looking. 

18 

19That is the cheapest possible false-green to close: "did the arm change 

20anything other than the thing that judges it" needs no model call, no 

21execution, and no judgement. 

22 

23What counts as production code 

24------------------------------ 

25``factory.diff_paths`` — the module ``bench/swebench_adapter.py`` also uses to 

26strip test edits out of a graded prediction and to refuse a prediction that 

27edits a pytest collection channel. This gate uses that module's STRICT 

28matcher (``is_test_code_path``), because a false positive here costs a real 

29merge while the bench's over-inclusive matcher only ever weakens an arm's own 

30patch; the two are one subset relation in one module, asserted by 

31``tests/test_diff_paths.py``. Measured cost of getting that wrong: the broad 

32matcher classifies ``factory/testing/flake.py`` — code THIS gate's sibling 

33imports — as a test. Production = not test code, and not a 

34collection/auto-import channel (``pyproject.toml``, ``pytest.ini``, ``tox.ini``, 

35``setup.cfg``, ``noxfile.py``, ``sitecustomize.py``, ``*.pth``, 

36``*pytest*plugin*.py``, ``conftest.py``). A story whose only non-test change is 

37pytest configuration is not a fix: measured against real pytest, ``addopts = 

38"-p _fixup"`` plus a collection hook makes the whole suite exit 0 with 

39"skipped". 

40 

41Docs, non-collection config and source all count as production. This gate asks 

42"was anything but the oracle touched", not "is this change interesting" — so a 

43docs-only TDD story still passes, and only a genuinely vacuous or 

44test-only/config-only diff blocks. 

45 

46Resolution order (every branch derives from a REAL artifact) 

47------------------------------------------------------------ 

481. ``pr.files_changed`` — GitHub's own file list for the PR. Only the 

49 ``--real-run`` CLI path populates it; the orchestrator's own ticks 

50 synthesize fixtures with ``files_changed=[]``, so in production this branch 

51 is usually empty and (2) carries the decision. 

522. ``pr.repo_root`` — ``git diff --name-only <base_ref>...HEAD`` in the story 

53 worktree, with the same ``origin/<base>`` → local ``<base>`` fallback 

54 (``handlers._resolve_diff_base``) the reviewer's diff and the docs-enforcer 

55 use, so all three agree about what the branch changed. COMMITTED work only: 

56 uncommitted edits are not what merges. Caveat inherited from that topology: 

57 the worktree can lag the pushed branch, so this reads the local commits, not 

58 the exact tree GitHub will squash. 

593. Real-run with a PR number and no usable worktree → ``gh pr diff 

60 --name-only``. This branch exists because ``_story_worktree`` swallows every 

61 failure into ``repo_root=None`` (a GC'd or unbuildable worktree), and without 

62 it a required fail-closed gate would turn any worktree fault into an 

63 unmergeable PR. It is LAST because it costs a GH API call per evaluation. 

644. Nothing derivable → BLOCK. There is deliberately no "assume it is fine" 

65 branch and no recorded-flag branch: ``evaluator.py`` (see the ALL_GATE_LABELS 

66 comment) records the precedent that a gate detached from a real check is 

67 worse than no gate, because it manufactures a verdict. 

68 

69Where this gate does NOT run (known, deliberate limits) 

70------------------------------------------------------ 

71* ``chain_kind == "docs"`` stories skip the whole gate evaluator 

72 (``auto_merge`` short-circuits to ``_DOCS_CHAIN_GATE_LABELS``). Harmless for 

73 this check — docs ARE production under this predicate, so a docs story would 

74 pass anyway. 

75* ``reconcile_from_github`` advances a PR merged out-of-band straight to 

76 ``deploy_pending``. An operator merging a PR by hand is an operator decision; 

77 no local gate is consulted, by design. 

78 

79This gate is in ``LOOP4_REQUIRED_GATE_LABELS``, i.e. merge-REQUIRED. That is 

80load-bearing: ``auto_merge`` computes ``missing_labels`` only over 

81``required_gate_labels(...)``, so a non-required gate's failure is filtered out 

82of the merge decision and the PR merges anyway. 

83"""

100def _git_changed_paths(repo_root: Path, base_branch: str) -> tuple[list[str] | None, str]: 

101 """``(paths, note)`` from ``git diff --name-only <base_ref>...HEAD``. 

102 

103 ``None`` means "could not derive" — a missing base ref, a git failure, a 

104 timeout. The caller fails closed on it; it never degrades to ``[]``, which 

105 would read as "the branch genuinely changed nothing". 

106 """ 

107 import subprocess 

108 

109 # Reuse the chain's own base-ref resolver rather than re-deriving the 

110 # fallback chain here: a gate that disagrees with the reviewer about the 

111 # diff base would block PRs the reviewer approved on a different diff. 

112 # Imported lazily — handlers is a heavy module and gates are imported by 

113 # the CLI. 

114 try: 

115 from factory.chain.handlers import _resolve_diff_base 

116 except Exception as exc: # noqa: BLE001 — fail closed, never wave through 

117 return None, f"could not import the diff-base resolver: {exc!r}" 

118 

119 base_ref = _resolve_diff_base(repo_root, base_branch) 

120 if base_ref is None: 

121 return None, ( 

122 f"no diff base ref: neither 'origin/{base_branch}' nor " 

123 f"'{base_branch}' resolves in {repo_root}" 

124 ) 

125 try: 

126 proc = subprocess.run( 

127 ["git", "diff", "--name-only", f"{base_ref}...HEAD"], 

128 cwd=str(repo_root), 

129 capture_output=True, 

130 text=True, 

131 errors="replace", # paths are arbitrary bytes; never strict-decode-crash 

132 check=False, 

133 timeout=60, 

134 ) 

135 except Exception as exc: # noqa: BLE001 — any git/OS failure fails CLOSED 

136 return None, f"git diff --name-only failed: {exc!r}" 

137 if proc.returncode != 0: 

138 return None, ( 

139 f"git diff --name-only {base_ref}...HEAD exited " 

140 f"rc={proc.returncode}; stderr_tail={proc.stderr.strip()[-200:]!r}" 

141 ) 

142 return [line.strip() for line in proc.stdout.splitlines() if line.strip()], ( 

143 f"git diff --name-only {base_ref}...HEAD" 

144 )

147def _gh_changed_paths(pr_number: int, repo: str) -> tuple[list[str] | None, str]: 

148 """``(paths, note)`` from ``gh pr diff --name-only``. ``None`` on any failure.""" 

149 import subprocess 

150 

151 try: 

152 proc = subprocess.run( 

153 ["gh", "pr", "diff", str(pr_number), "--name-only", "--repo", repo], 

154 capture_output=True, 

155 text=True, 

156 errors="replace", 

157 check=False, 

158 timeout=120, 

159 ) 

160 except Exception as exc: # noqa: BLE001 — fail closed 

161 return None, f"gh pr diff --name-only failed: {exc!r}" 

162 if proc.returncode != 0: 

163 return None, ( 

164 f"gh pr diff --name-only #{pr_number} exited rc={proc.returncode}; " 

165 f"stderr_tail={proc.stderr.strip()[-200:]!r}" 

166 ) 

167 return [line.strip() for line in proc.stdout.splitlines() if line.strip()], ( 

168 f"gh pr diff --name-only #{pr_number}" 

169 )

172def evaluate(pr: PRContext, app_config: AppConfig) -> GateResult: 

173 label = _LABEL 

174 

175 paths: list[str] | None = None 

176 source = "no files_changed, no repo_root, no PR to query" 

177 if pr.files_changed: 

178 paths = list(pr.files_changed) 

179 source = "pr.files_changed (GitHub)" 

180 elif pr.repo_root is not None: 

181 paths, source = _git_changed_paths(pr.repo_root, pr.base_branch or "main") 

182 if paths is None and not pr.dry_run and pr.pr_number > 0 and app_config.repo: 

183 # Last resort, and the reason a worktree fault cannot wedge a merge. 

184 gh_paths, gh_source = _gh_changed_paths(pr.pr_number, app_config.repo) 

185 if gh_paths is not None: 

186 paths, source = gh_paths, gh_source 

187 else: 

188 source = f"{source}; {gh_source}" 

189 

190 if paths is None: 

191 return GateResult( 

192 label=label, 

193 passed=False, 

194 reason=f"cannot determine the changed files, so cannot prove production code changed: {source}", 

195 details={"source": source, "authoritative": False}, 

196 ) 

197 

198 production = production_paths(paths) 

199 if production: 

200 return GateResult( 

201 label=label, 

202 passed=True, 

203 reason=f"{len(production)} production file(s) changed", 

204 details={ 

205 "source": source, 

206 "production_paths": production[:20], 

207 "changed_count": len(paths), 

208 "authoritative": True, 

209 }, 

210 ) 

211 

212 # Zero production files. Say WHICH kind of vacuous this is — a 0-file diff 

213 # and a test-only diff need different operator responses. 

214 test_only = [p for p in paths if is_test_code_path(p)] 

215 config_only = [ 

216 p for p in paths if not is_test_code_path(p) and is_collection_channel_path(p) 

217 ] 

218 if not paths: 

219 detail = "the diff is EMPTY — nothing was committed on this branch" 

220 else: 

221 detail = ( 

222 f"the diff touches only test files ({len(test_only)}) and pytest " 

223 f"collection config ({len(config_only)})" 

224 ) 

225 return GateResult( 

226 label=label, 

227 passed=False, 

228 reason=f"no production-code change: {detail}", 

229 details={ 

230 "source": source, 

231 "changed_paths": paths[:20], 

232 "test_paths": test_only[:20], 

233 "collection_config_paths": config_only[:20], 

234 "authoritative": True, 

235 }, 

236 )
